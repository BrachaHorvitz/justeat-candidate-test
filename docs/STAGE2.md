# Stage 2 — Automated Reporting

The management team asks the same question every day: **"How many employees are currently in each department?"**

The goal: anyone on the team should be able to ask the AI tool this question and get an immediate, reliable answer — without touching the code, without running a query manually, every single time.

The answer must always appear in this exact format:

```
מחלקה        | עובדים
-------------|--------
HR           | 8
R&D          | 14
Maintenance  | 10
Sales        | 9
Finance      | 9
```

Set this up so it works consistently for everyone, every time.
